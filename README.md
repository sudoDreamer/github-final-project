# Simple Interest Calculator

This project is a simple Bash script that calculates simple interest based on the principal amount, annual rate of interest, and time period in years.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Usage

Run the script using:

bash simple-interest.sh

Enter the principal amount, rate of interest, and time period when prompted.
